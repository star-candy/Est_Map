# 실제 서울 데이터 연결 조사 (2026-09-08 확인)

공식 제공처에서 확인한 범위만 기록한다. 확인하지 못한 값은 `미확인`으로 둔다.
원본은 `data/raw/`(Git 제외) → 검증 → `data/processed/` 순서로 처리한다.

## 공통 조건

- 서울 열린데이터광장 Open API는 발급 키를 URL 경로에 넣고 요청당 최대 1,000건을
  조회한다. 파일과 API 조건은 각 상세 페이지에서 따로 확인한다.
- 공공누리 제1유형은 출처표시가 필요하다. 제4유형은 출처표시·비영리·변경금지
  조건이 있어 변환·공개·서비스 이용 가능성을 제공기관에 먼저 확인한다.
- 지도/리포트에 데이터명, 제공기관, 기준일, 공식 URL, 라이선스를 표시한다.

## 1. 가로수와 은행나무

### 최신 파일 후보: 서울시 가로수 위치 정보(경도, 위도)

- 제공처: 서울특별시 푸른도시여가국 조경과 / 서울 열린데이터광장
- URL: https://data.seoul.go.kr/dataList/OA-22904/S/1/datasetView.do
- 형식·인증: XLSX. Sheet/Open API 표기는 실제 명세 확인이 필요하다.
- 갱신: 연간. 확인 당시 2026년 파일, 수정일 2026-08-26
- 좌표계·컬럼: 자치구, 노선, 수종, 경도, 위도는 확인했다. EPSG는 미확인이다.
- 라이선스: 공공누리 제4유형
- 전처리: 헤더/CRS·서울 경계 검사, 중복·결측 제거, 수종명 표준화, edge buffer
  집계. 변환 허용 여부를 먼저 확인한다.
- 지원/한계: 은행나무 전체 밀도 proxy 후보이다. 암수 필드는 확인되지 않았다.
  검증된 암수 정보가 없으면 **은행나무 전체 회피**로 동작하고 UI에 표시한다.

좌표계 명시 대안 `서울시 가로수 위치정보 (좌표계: ITRF2000)`은
https://data.seoul.go.kr/dataList/OA-320/A/1/datasetView.do 에서 제공한다. 서울 API
키와 서비스명 `GeoInfoRoadsideTree`를 사용하며 비정기 갱신, 페이지 수정일
2022-10-14, 공공누리 제1유형이다. 제목은 ITRF2000, 본문은 GRS80TM으로 표기되어
원본 명세 확인이 필요하다. `ITEM_TRSPC`(품계수종)는 확인했지만 암수 컬럼은
확인되지 않았다. WGS1984 대안
https://data.seoul.go.kr/dataList/OA-1325/S/1/datasetView.do 는 본문상 구축 당시
종로구가 누락되어 서울 전역 자료로 간주하지 않는다.

## 2. 그늘막

- 제공처: 서울특별시 재난안전실 재난안전예방과 / 서울 열린데이터광장
- 데이터명·URL: `서울시 그늘막 현황`,
  https://data.seoul.go.kr/dataList/OA-22309/F/1/datasetView.do
- 형식·인증: XLSX 다운로드. 별도 API 인증은 확인되지 않았다.
- 갱신: 변동 시 비정기. 파일 기준일 2026-07-31, 수정일 2026-08-06
- 좌표계·컬럼: 좌표계 미확인. 유형, 시도, 시군구, 설치장소명, 설치위치,
  설치일시, 행정동, 도로명주소, 지번주소, 관리번호를 확인했다.
- 라이선스: 공공누리 제1유형
- 전처리: 주소 정제·지오코딩, 서울 경계/정확도 검사, 중복 제거, edge 거리 계산
- 지원/한계: 지점 주변 그늘시설 proxy는 가능하다. 좌표, 차양 면적·방향·운영 상태,
  시간별 그림자는 확인되지 않아 정밀 그늘 계산을 지원하지 않는다.

## 3. 도로 열선

- 제공처: 서울특별시 재난안전실 도로관리과 / 서울 열린데이터광장
- 데이터명·URL: `서울시 열선 설치 현황`,
  https://data.seoul.go.kr/dataList/OA-22584/F/1/datasetView.do
- 형식·인증: CSV 다운로드. 별도 API 인증은 확인되지 않았다.
- 갱신: 변동 시 비정기. 최신 확인 파일 기준일 2026-05-31, 수정일 2026-06-11
- 좌표계·컬럼: 좌표/geometry는 미확인. 관리기관, 설치연도, 설치구간, 연장을 확인했다.
- 라이선스: 공공누리 제4유형
- 전처리: 설치구간 텍스트 정제, 후보 도로 geometry에 map-match, 사람 검수·신뢰도
  기록. 길이 단위는 원본에서 확인한다.
- 지원/한계: 설치구간 선호 proxy는 가능하다. 가동 여부, 실시간 상태, 노면온도,
  결빙 위험은 확인되지 않았다. 변환 이용 허용 여부를 먼저 확인한다.

- 좌표계·컬럼: 위도·경도 제공은 확인했으나 EPSG와 전체 헤더는 미확인이다.
- 라이선스: 공공누리 제1유형

  골목 보안등 포괄 여부는 확인되지 않아 실제 야간 안전을 보장하지 않는다.

## 5. 따릉이 대여소

- 제공처: 서울특별시 교통실 자전거정책과 / 서울 열린데이터광장
- 데이터명·URL: `서울시 공공자전거 따릉이 실시간 대여정보`,
  https://data.seoul.go.kr/dataList/OA-15493/A/1/datasetView.do
- 형식·인증: JSON Open API, `SEOUL_OPEN_API_KEY`. 요청당 최대 1,000건이다.
  명세에서 확인한 서비스명을 `SEOUL_BIKE_API_SERVICE`에 설정한다.
- 갱신: 수시/실시간 성격. 페이지 수정일 2026-09-08
- 좌표계·컬럼: 위도, 경도, 대여소 ID·명, 거치대 수, 현재 자전거 수, 이용률은
  확인했다. EPSG와 실제 JSON 키는 명세에서 확정한다.
- 라이선스: 공공누리 제1유형
- 전처리: pagination, 숫자/결측·서울 경계 검사, 조회시각 저장, 필드 의미 확인
- 지원/한계: 출발지 대여 가능성은 지원한다. 반납 가능 거치대가 직접 제공되는지
  확정할 수 없어 임의 계산하지 않고 확인 전 도착 대여소 추천을 비활성화한다.

## 6. 서울 기상·자외선

### 단기예보

- 제공처: 기상청 / 공공데이터포털
- 데이터명·URL: `기상청_단기예보 조회서비스`,
  https://www.data.go.kr/data/15084084/openapi.do
- 인증: 활용 신청 후 `KMA_DATA_API_KEY`, JSON/XML
- 갱신·공간단위: 초단기·단기 발표 주기, 전국 5 km × 5 km 격자
- 좌표계·필드: 위경도를 API 격자로 변환한다. 기온, 습도, 풍향·풍속, 강수 등은
  확인했으며 정확한 키와 단위는 선택 operation의 최신 명세를 따른다.
- 라이선스: 공공누리 제1유형. 제3자 권리·저작권 표시 안내도 확인해야 한다.
- 전처리/한계: 격자 변환, 발표·예보시각 정렬, 단위/결측 검증, TTL 캐시.
  날씨 안내에는 유용하지만 edge별 그늘이나 결빙을 직접 측정하지 않는다.

### 생활기상지수(자외선)

- 제공처: 기상청 / 공공데이터포털
- 데이터명·URL: `기상청_기상청_생활기상지수 조회서비스(4.0)`,
  https://www.data.go.kr/data/15085288/openapi.do
- 인증: 활용 신청 후 `KMA_DATA_API_KEY`, JSON/XML
- 갱신: 공식 변경 공지상 자외선은 오늘~글피, 3시간 단위·3시간 간격 생산이다.
  현재 operation별 주기는 활용 명세에서 재확인한다.
- 좌표계·필드: 자외선지수·대기정체지수 제공은 확인했다. 지역 식별 방식, 실제 키,
  단위와 좌표계는 명세 다운로드 전 미확인이다.
- 라이선스·표시: 활용 신청 시 상세 이용허락범위와 저작권 표시문구를 재확인한다.
- 전처리/한계: 서울 지역 매핑, 발표시각 정렬, 등급/수치 분리, TTL 캐시.
  권역 안내에는 유용하지만 가로별 일사량이나 실제 그늘을 뜻하지 않는다.

## 실제 adapter 상태

- `src/data_sources/base.py`: 공간자료·기상 공급자 인터페이스와 provenance
- `src/data_sources/seoul.py`: 서울 API 클라이언트, CSV/GeoJSON 로더, 명시적 필드
  매핑을 요구하는 따릉이 adapter
- `src/data_sources/kma.py`: 명세/operation 고정 전 필드를 추측하지 않는 KMA 경계
- 실제 adapter는 앱 시작 시 자동 생성되지 않는다. 키/파일이 없으면 기존 샘플
  따릉이 공급자와 합성 지표가 계속 동작한다.

## 개발자 제공 체크리스트

- [ ] `SEOUL_OPEN_API_KEY`: 서울 열린데이터광장 인증키
- [ ] `SEOUL_BIKE_API_SERVICE`: 따릉이 명세에서 확인한 정확한 서비스명

- [ ] 따릉이 JSON 명세(필드명·단위·반납 가능 거치대 의미) 버전 고정
