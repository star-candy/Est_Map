# 개인정보·AI 책임성 점검표

이 문서는 서울 쾌적 경로 앱의 현재 구현을 기준으로 개인정보, AI 결과, 편향과 사용자
안내를 점검한 결과입니다.

## 개인정보와 비밀정보

| 점검 항목 | 상태 | 구현 근거 |
|---|---|---|
| 불필요한 개인정보를 입력받지 않음 | 충족 | 이름·전화번호·주민등록번호 입력란이 없음 |
| 필요한 정보만 사용 | 충족 | 경로 계산에 출발지·도착지만 사용하며 좌표 직접 입력 가능 |
| 정밀 이동정보 최소 저장 | 충족 | SQLite에는 월, 거리, 경로 종류, 탄소·비용 집계만 저장 |
| 외부 전송 안내 | 충족 | 입력 전 안내에서 Nominatim, TMAP, Google로 전달되는 항목 명시 |
| API 키 비노출 | 충족 | 키는 Git에서 제외된 `.env`에서만 읽고 UI·로그에 출력하지 않음 |

공공 시설의 주소와 좌표는 경로 지표 생성에 사용하지만 사용자 개인의 주소나 이동 경로로
저장하지 않습니다. 사용자는 주소 입력란에 이름, 전화번호 등 개인식별정보를 함께 적지
않아야 합니다.

## AI 결과와 편향

| 점검 항목 | 상태 | 구현 근거 |
|---|---|---|
| AI 결과를 사실로 단정하지 않음 | 충족 | 모든 모드에 참고용·오류 가능·안전 비보장 문구 표시 |
| 실패 시 안전한 처리 | 충족 | RL 실패 시 weighted A*, OSM 실패 시 오류로 종료 |
| 편향 가능성 안내 | 충족 | 공공데이터 누락과 지역별 시설 밀도 차이를 UI에 명시 |
| 중요한 판단을 AI가 단독 결정하지 않음 | 충족 | 공식 안전 경로가 아님을 표시하고 일반 경로와 함께 비교 |

다음 편향은 제거됐다고 단정할 수 없습니다.

- 가로등과 안심귀갓길 시설이 많은 지역이 더 높은 안심 점수를 받습니다. 시설이 적게
  기록된 지역은 실제 환경과 무관하게 낮게 평가될 수 있습니다.
- 가로수·그늘막·열선 자료의 갱신일과 공간 정확도가 자치구별로 다를 수 있습니다.
- 맛집은 Google 평점·리뷰 수가 많은 업소가 유리해 신규·소규모 업소가 덜 노출될 수
  있습니다.
- RL은 검색 구간의 제한된 부분 그래프에서 학습하므로 서울 전체의 최적성을 보장하지
  않습니다.

## 사용자 경험과 오류 메시지

| 상황 | 사용자 안내와 복구 방법 |
|---|---|
| 주소를 찾지 못함 | 주소 확인 또는 좌표 직접 입력 안내 |
| 서울 밖 좌표 | 서울 범위 밖임을 표시하고 계산 중단 |
| OSM 보행망 실패 | 합성 경로를 만들지 않고 연결 실패 표시 |
| 실제 데이터 전처리 실패 | 필요한 전처리 파일 확인 안내 |
| RL 추론 실패 | 원시 예외를 숨기고 weighted A* 사용 사실 표시 |
| 맛집 API 실패 | 재시도 또는 API 설정 확인 안내; 경로 결과는 유지 |
| TMAP 택시요금 실패 | 서울 택시요금 가정식 사용 사실 표시 |
| Gemini 실패 | 재시도 안내와 템플릿 리포트 유지 |

## 데이터 사용 조건

데이터셋별 제공처, URL, 좌표계, 전처리와 알려진 라이선스는
[`data/README.md`](../data/README.md)에 기록합니다. 공식 URL이나 라이선스가 첨부
파일만으로 확인되지 않은 자료는 확인 완료로 표시하지 않으며 실제 배포 전에 제공처의
최신 이용조건을 다시 확인해야 합니다.
